PROBLEM STATEMENT
  1. 01Lab D lacks a dedicated, production-grade cybersecurity and networking laboratory.
  2. 02Existing solutions are too costly or hard to maintain at university scale.
  3. 03Persistent gap between the practical skills demanded by the cybersecurity and networking industry and the hands-on competencies that graduates are able to demonstrate upon entering the workforce.
  4. 04The university's existing hardware remains underutilised.
Research Design Table (RDT)
No. Research Question Research Objective Methods Expected Outcome
RQ1 How can the existing Lab D hardware at UOWM be repurposed into a scalable, multi-node virtualised cybersecurity and networking education platform using open-source tools? To design and deploy a Proxmox VE-based virtualisation cluster using existing Lab D hardware, capable of hosting multiple concurrent student VM sessions. Literature ReviewStudy Existing Systems A deployed and operational Proxmox VE cluster on Lab D hardware with documented physical and logical topology.
RQ2 How can a realistic virtual network environment be configured to provide students with hands-on experience in networking and cybersecurity tasks? To configure a production-grade virtual network infrastructure using open-source tools, providing a realistic environment for networking and cybersecurity lab exercises. Observation A fully functional prototype of the system to simulate the learning environment.
RQ3 Can the platform effectively support student learning in networking and cybersecurity, as assessed through user acceptance testing? To evaluate the usability and educational effectiveness of the platform through user acceptance testing with student participants. Questionnaire / SurveyUser Acceptance Testing Validated platform with UAT results demonstrating acceptable usability scores and the success of deploying cybersecurity and networking labs.
Project Scope
Level Scope Description
Basic
  1. The system shall allow the communication between end user device like Dell to the Acer desktop
  2. The system shall have monitoring capabilities
  3. The system shall provide a network learning environment to students with instructions
  1. The hardware is connected together with network switches to allow connection between them
  2. The system is configured with a monitoring tool to monitor resource usage with Grafana or teammates' dashboard as display
  3. The system provides VMs for students to configure networking
Intermediate
  1. The system has security features designed into the networking framework of the platform
  1. VLAN segmentation and other network security features will be implemented for the Proxmox nodes and VMs
Advanced
  1. The system will trigger alerts for critical events
  2. The system allows future addition of more labs with a manual on how to do so
  1. Alert events are based on data from the monitoring tools to detect and give off alerts
  2. The system is designed in a way that it is easy to configure new labs
