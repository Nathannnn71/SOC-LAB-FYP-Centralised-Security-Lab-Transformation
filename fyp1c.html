Modernizing Cybersecurity Teaching Infrastructure Through Automation

PROBLEM STATEMENT
  • Lack of an automated laboratory environment in cybersecurity education at UOW Malaysia
    Students must manually configure virtual machines which result in inconsistent configurations and setup failures (Al-Zubaidie et al., 2024)
    Traditional on-premises labs face high maintenance costs, limited accessibility, and hardware constraints (Khan & Mohamed, 2025)
    Container-based cyber range platforms still require infrastructure complexity and administrative overhead (Chouliaras et al., 2023)
    EDURange provides browser-based exercises but lacks external device integration and remains dependent on external infrastructure (Lundqvist et al., 2025)
    Students spend excessive time troubleshooting technical setup issues instead of developing practical cybersecurity skills
  • Root cause: absence of a centralized and automated laboratory infrastructure
  • Solution required: leverage automation and Infrastructure-as-Code (IaC) to enable automated cybersecurity lab infrastructure
RESEARCH OBJECTIVES
  1. To integrate Infrastructure-as-Code (IaC) and automation tools such as Terraform, Ansible, and GitLab CI/CD in automating the provisioning, configuration, and lifecycle management of cybersecurity lab environments.
  2. To design and develop a centralized and automated virtualization infrastructure using Proxmox Virtual Environment (VE) to provide standardized cybersecurity lab environments.
  3. To validate the effectiveness of the automated laboratory infrastructure in enhancing practical cybersecurity learning and reducing environment setup issues for students.
RESEARCH QUESTIONS
  1. How can infrastructure automation tools such as Terraform, Ansible, and GitLab CI/CD be integrated to enable efficient deployment, configuration, and management of cybersecurity lab environments?
  2. How can a centralized and automated virtualization infrastructure be designed to support consistent and scalable cybersecurity laboratory environments?
  3. How effective is the proposed automated cybersecurity laboratory infrastructure in improving hands-on learning experiences and reducing setup complexity for cybersecurity students?
SCOPE OF PROJECT
Level Function Description
Basic
  1. The system shall be able to create standardized golden virtual machine templates.
  2. The system shall be able to deploy virtual machines from templates for learning purposes.
  1. The system will prepare preconfigured virtual machine images for student use.
  2. The system will create new lab environments by cloning existing templates.
Intermediate
  1. The system shall be able to automate the provisioning of virtual machines across cluster nodes.
  2. The system shall be able to automatically configure lab environments after deployment.
  3. The system shall be able to reset or restore lab environments to a clean state.
  1. The system will automatically deploy virtual machines to available computing nodes based on resource availability.
  2. The system will automatically install required tools once virtual machines are created.
  3. The system will support several classes running different lab environments concurrently.
Advance
  1. The system shall be able to deploy complete lab scenarios for different cybersecurity courses.
  2. The system shall be able to support scalable and repeatable lab delivery for multiple classes
  1. The system will launch full lab setups depending to subjects such as Penetration Testing.
  2. The system will enable the same lab setup to be reused across different semester and classes with minimal configuration.
